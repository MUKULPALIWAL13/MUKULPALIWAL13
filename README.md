### Projects

<details open>
<summary><b> Digital Design & Hardware Acceleration</b></summary>
<br/>

**FPGA-based MNIST Handwritten Digit Recognition Pipeline**
Built an entire pipeline, from camera interface to display — preprocessing, grayscale conversion, flattening, and a custom neural network inference core. Verified with a custom Cocotb + Python testbench in Xilinx Vivado.

**AXI-compliant LFSR IP Core**
A complete AXI4-Lite and AXI4-Stream compatible IP block for pseudorandom number generation, integrated with Block RAM and FIFOs, verified via a Python AXI master testbench.

**16-Point FFT ASIC Design Flow**
RTL implementation of a Radix-2 DIT FFT processor, pushed through synthesis, floorplanning, and Place & Route using the OpenLane ASIC flow, meeting timing and area constraints.

**CORDIC Calculator**
Synthesizable Verilog implementation for computing fixed-point sine and cosine values using an iterative micro-rotation algorithm.

**Signed Booth Multiplier**
Verilog implementation of signed binary multiplication, optimized to reduce hardware area and propagation delay.

</details>

<details>
<summary><b> Analog & Mixed-Signal Design</b></summary>
<br/>

**180nm CMOS Differential Amplifier**
Designed and simulated a fully differential CMOS op-amp in LTspice on a 180nm node — optimizing circuit geometry and biasing networks to maximize differential-mode gain and CMRR while balancing power dissipation and unity-gain bandwidth.

</details>

<details>
<summary><b> Low-Level Systems & Embedded Infrastructure</b></summary>
<br/>

**Bare-metal Operating System for Raspberry Pi 2**
Built from scratch with no external OS support: custom UART drivers, user-to-kernel privilege transition protocols (ARM EL0 → EL1 switching), MMU-based virtual memory setup, and interrupt-driven syscall infrastructure.

**RISC-V Single-Cycle and Pipelined Processors**
Designed complete datapath and control units in Verilog. Resolved pipeline stalls with automated hazard-detection and forwarding logic, backed by an assembler-based test workflow.

**ESP32 Secure NVS Data Extraction and Cryptography**
Reverse-engineered and extracted data from ESP32 Non-Volatile Storage (NVS), then engineered a secure transmission pipeline to a remote server protected by a custom, lightweight SHA-256 workflow.

**IoT-based Smart Fan Controller**
A low-power ESP32 ambient monitoring system that uses real-time temperature tracking to modulate motor speeds, with cloud updates.

</details>
